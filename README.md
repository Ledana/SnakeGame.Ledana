# 🐍 Snake Console Game

A simple **Snake game** built in C# as a console application.  
This project demonstrates my understanding of programming fundamentals, logic, and game loop design.

---

## 🎯 Features
- Classic snake gameplay in the console window
- Snake grows when eating food
- Collision detection with walls and self
- **Game ends when the snake collides** (final score is displayed)
- Score tracking

---

## 🛠️ Tech Stack
- **Language:** C#
- **Framework:** .NET Console Application
